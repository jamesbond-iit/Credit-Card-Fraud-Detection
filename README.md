# 💳 Credit Card Fraud Detection Using Neural Networks

A deep learning based machine learning project that detects fraudulent credit card transactions using an Artificial Neural Network (ANN). The project also compares the performance of Neural Networks with Logistic Regression, Support Vector Machine, Random Forest, XGBoost, and Multi-layer Perceptron (MLP).

## 📌 Project Overview

Credit card fraud detection is a highly imbalanced binary classification problem. This project applies preprocessing, undersampling, feature scaling, and several classification models to identify fraudulent transactions effectively.

## 📂 Dataset

- Dataset: Credit Card Fraud Detection Dataset (MLG-ULB, Kaggle)
- 284,807 transactions
- 492 fraudulent transactions

Download `creditcard.csv` from Kaggle and place it in the repository root.

## 🧠 Models Implemented

- Logistic Regression
- Support Vector Machine
- Random Forest
- XGBoost
- MLP Classifier
- TensorFlow / Keras ANN

## ⚙️ Technologies Used

Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, TensorFlow/Keras, XGBoost, Imbalanced-learn.
